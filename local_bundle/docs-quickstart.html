Quick Start

Run your first security scan in 60 seconds.

1. Recon Scan

# Full passive + active recon shadow313 recon --target example.com --mode full # Passive only with stealth mode shadow313 recon --target example.com --mode passive --stealth [+] DNS: 7 record types resolved [+] Subdomains: 23 discovered via CT logs [+] Ports: 3 open (80, 443, 8080) [+] AI Profile: Generated attack surface summary

2. Vulnerability Scan

shadow313 vuln --target example.com --epss --kev [!] CVE-2024-3400: EPSS=0.971 KEV=YES CVSS=10.0 [!] CVE-2023-46604: EPSS=0.934 KEV=YES CVSS=9.8

3. Quantum Audit

shadow313 quantum --target example.com --scan tls [+] ML-KEM-768: COMPLIANT (FIPS 203) [!] RSA-2048: LEGACY_UNSAFE — migrate to ML-DSA-65
