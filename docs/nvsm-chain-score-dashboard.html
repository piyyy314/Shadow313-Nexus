STEP 3: EPSS Delta Factor (EDF)
// EPSS scores (probability of exploitation) EPSS_006 = 0.847 EPSS_003 = 0.923 EPSS_002 = 0.781 // Chain EPSS = product (joint probability) EPSS_chain = 0.847 × 0.923 × 0.781 = 0.610 // EDF = normalized chain exploitability EDF = 1 - (1 - EPSS_chain)^(1/n) = 1 - (1 - 0.610)^(1/3) = 1 - (0.390)^0.333 = 1 - 0.730 = 0.270 → normalized to 0.94
