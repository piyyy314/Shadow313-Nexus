How 313-BIND Works

1
Nanosecond Timestamp
time.time_ns() nudged to end in ...313. Provides entropy unique to each receipt.
2
SHA3-256 Payload Hash
Canonical JSON of the security finding is hashed. Any change breaks the hash.
3
SHA3-512 Chain Hash
Chain = hash(payload + prev_hash + timestamp). Sequential — gaps are instantly detected.
4
SLH-DSA Signature
FIPS 205 hash-based signature over chain_hash. Quantum-safe — survives CRQC attacks.

Verify via CLI (Offline)

You can verify any receipt without this portal using the Shadow313 CLI or raw cryptographic tools:

# Method 1: Shadow313 CLI
shadow313 verify 313-VSAT-A4F2C1
# Method 2: IPFS (if anchored)
ipfs cat QmX7k9abc123... | python3 -m json.tool
# Method 3: Manual SHA3-512 verification
echo -n '{"payload_hash":"...","timestamp_ns":...}' | sha3sum -a 512
# Method 4: Python (no dependencies)
python3 -c "import hashlib,json; d=json.load(open('receipt.json')); print(hashlib.sha3_512(json.dumps(d['payload'],sort_keys=True).encode()).hexdigest())"
