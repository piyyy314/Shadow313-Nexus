Key Bug Fixes (v1 to v4)
Config.set()
Key-path order was reversed — fixed to (*keys, value)
AIEngine._ollama_stream()
Infinite loop risk if done key never arrived — added 10,000 packet counter guard
AIEngine.chat()
No context truncation — added _truncate_context() with 12,000 char limit
CVEDatabase
references is a reserved SQLite keyword — renamed column to refs
TemporalBindingEngine._wait_for_313()
Busy-loop with no sleep — added 0.1ms sleep
DNSCovertDetector
Shannon entropy used math.log() without base — fixed to math.log2()
JA3Scanner
GREASE value set was incomplete (missing 0x8A8A) — completed RFC 8701 set
