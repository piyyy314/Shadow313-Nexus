What Recon Does

🔍

DNS Enumeration

A, AAAA, MX, NS, TXT, CNAME, SOA record lookups against authoritative and recursive resolvers via dnspython / stdlib resolver.

🌐

Subdomain Discovery

Certificate Transparency log queries (crt.sh API) combined with wordlist brute-force. Parallel execution. Deduplication and resolution.

⚡

Async Port Scanning

asyncio TCP connect scan. Supports port ranges (1-1024) and explicit lists (80,443,8080). Pure-Python stdlib — no scapy dependency.

🖥

Web Fingerprinting

15 technology signatures: WordPress, Nginx, Apache, Django, Laravel, React, Vue, Angular, PHP, ASP.NET, IIS, Tomcat, Flask, Express, CMS.

📋

WHOIS + GeoIP

Registrar, creation date, expiry, nameservers via python-whois. GeoIP enrichment via ip-api.com: country, city, ASN, ISP per discovered IP.

🤖

AI Target Profiling

LLM synthesizes all gathered recon data into a structured threat profile with attack surface summary and recommended next steps.

CLI Reference

Recon Commands

# Full passive + active recon
shadow313 recon --target example.com --mode full

# Active scan on IP range
shadow313 recon --target 192.168.1.0/24 \
  --mode active --ports 1-1024

# Passive only with stealth mode
shadow313 recon --target example.com \
  --mode passive --stealth

# Custom ports + JSON output
shadow313 recon --target example.com \
  --ports 80,443,8080 --output json

# Custom subdomain wordlist
shadow313 recon --target example.com \
  --wordlist ./subdomains.txt

Flags Reference

FlagDescription

Workflow

How Recon Works

1. Normalize target input

Detect domain vs. IP vs. CIDR vs. URL; extract hostname.

2. DNS enumeration

Resolve all 7 record types for the target domain.

3. Subdomain discovery

Query crt.sh CT logs + brute-force wordlist in parallel.

4. Async port scan

TCP connect across configured port range; collect banners.

5. Web fingerprinting

HTTP GET to open ports; match 15 technology signatures.

6. WHOIS + GeoIP enrichment

Enrich each discovered IP with registrar data and geographic/ASN info.

7. AI target profiling

LLM generates attack surface summary from aggregated data.

8. Write outputs + fire hooks

Write recon.json and target.json to session directory; fire recon.post plugin hook.
