Key Findings
Arch-E Is the Unguarded Back Door
Arch-E credential reuse achieves $7.38B loss with only 0.5h adaptation delay — nearly identical to the unhardened baseline. The $0.8M surgical hardening saved only $1.17B against this counter-strategy.
Adaptation Delay Is the Defender's Only Window
Every adversarial pivot requires 0.5h–4.0h adaptation time. This window is the defender's only opportunity to extend hardening before the attacker re-enters.
The Most Sophisticated Attack Is Least Effective
Custom SWIFT Web RCE achieves the lowest loss ($4.52B) because it enters via Arch-C (60-80% CSP). Simple Arch-E credential reuse achieves $7.38B with zero new exploit development.
Hardening Must Cover the Full T24 Cluster
Surgical top-5 hardening leaves 10 Arch-E and 8 Arch-A institutions with shared T24 credentials unprotected. Complete defense requires hardening all 24 T24 shared-credential institutions.
