⚠ Performance Findings
Unverified historical note: Threat Board page complexity
s313-threat-board.html (83.6KB) has 3 setInterval animation loops and 30KB of inline ATT&CK DRILLDOWN data. The page contains browser-side animation loops; actual CPU and concurrency impact has not been measured here. A proposed Visibility API approach can pause background animation loops; no reproducible CPU benchmark is published here.
Unverified historical note: Project Roadmap page complexity
project-roadmap.html (55.4KB) has 1 canvas element and 12KB of JS for the effort/impact scatter chart. No animation loops. The page contains a canvas chart. No controlled concurrent-load test or performance conclusion is published here.
Unverified historical note: priority-page complexity
Ghost-Watch Threat Map, ML Predictor, Threat Actor Map, Plugin Studio, and SOAR Playbook Builder their current performance has not been measured. No canvas, no animation loops, no external JS dependencies. These pages will handle high concurrent load without degradation.
Unverified historical response-time claim — do not use as a benchmark
No reproducible timing dataset, test harness, CDN trace, or concurrency evidence is attached. Static HTML alone does not establish edge latency or the absence of all bottlenecks.
✅ Optimizations Applied & Recommendations
Suggested: Visibility API (Threat Board)
Design note: pause background animation loops with the Visibility API. Performance impact requires measurement in a controlled browser benchmark.
Unverified historical note: will-change CSS hints
The suggested CSS hints may affect compositing and paint behavior. No before/after browser profile is published to quantify an improvement.
Unverified historical note: Google Fonts preconnect
Added <link rel="preconnect"> for fonts.googleapis.com and fonts.gstatic.com. Preconnect may reduce connection setup time in some environments. No measured First Contentful Paint result is supplied.
Recommended: Lazy-Load ATT&CK Data (Threat Board)
The 30KB DRILLDOWN constant in s313-threat-board.html could be moved to a separate JSON file loaded on first user interaction with the ATT&CK matrix. Potential optimization only; no before/after profile or mobile benchmark is available.
CDN performance — not measured
The repository contains static HTML pages. Current deployment routing, CDN cache behavior, TTFB, FCP, LCP, and mobile network performance have not been measured in a reproducible current-environment test.
