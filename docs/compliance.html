Cryptographic Standards

FIPS 203

ML-KEM-768

Module-Lattice-Based Key-Encapsulation Mechanism. Replaces RSA and ECDH for quantum-safe key exchange. Implemented via liboqs (proxy) and quantcrypt.

✅ IMPLEMENTED
FIPS 204

ML-DSA-65

Module-Lattice-Based Digital Signature Algorithm. Replaces ECDSA for digital signatures. Currently implemented as HMAC-SHA256 proxy; full liboqs migration planned Q4 2026.

⚠ PROXY (DW-1)
FIPS 205

SLH-DSA-SHAKE-128f

Stateless Hash-Based Digital Signature Standard. Used for 313-BIND receipt signing and root of trust. Implemented via pyspx. Quantum-safe by design.

✅ IMPLEMENTED
