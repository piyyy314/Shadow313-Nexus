Hardening & Best Practices

Downloadable checklists for configuration, architecture, monitoring, and resilience.

Configuration Hardening

  • Change all default credentials and enforce strong passwords.
  • Disable HTTP, Telnet, and SNMPv1/v2c management.
  • Require HTTPS (TLS 1.2+) and SSH for admin access.
  • Enable SNMPv3 with auth and privacy.
  • Require signed firmware images only.

Network Architecture

  • Place VSAT modems in dedicated VLANs and zones.
  • Restrict management access via firewalls/jump hosts.
  • Deploy IDS/IPS on VSAT segments.
  • Use VPN / encrypted tunnels for sensitive traffic.
  • Segment OT/SCADA behind DMZ or air‑gap where feasible.

Monitoring & Detection

  • Baseline latency, jitter, packet loss, and SNR/BER.
  • Use 3‑sigma thresholds for anomaly detection.
  • Centralize modem and NMS logs to a SIEM.
  • Alert on auth failures, config changes, firmware updates.

Resilience & Failover

  • Design multi‑path networking (VSAT plus terrestrial backup).
  • Plan graceful degradation for critical services.
  • Conduct regular failover and DR exercises.
  • Define and test RTO/RPO for key workloads.
