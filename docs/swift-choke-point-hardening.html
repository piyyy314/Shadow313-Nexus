Key Findings
5 Nodes Stop the Entire Cascade
Hardening just 5 Arch-D institutions at T+5h reduces compromised institutions from 50 to 0 and saves $8.55B. Cost: $0.8M. Deploy: 6 hours. ROI: 10,689×.
Correspondent Bridge Hardening Is Insufficient
Hardening all 14 Arch-B correspondent bridges only saves $1.13B (13% of baseline). The cascade bypasses Arch-B via direct credential reuse between T24 institutions.
The Real Choke Point Is the Credential Vector
Institution-level isolation only works when it removes a credential hub. Hardening Arch-D (CRITICAL shared creds + Fed) stops the cascade entirely.
More Nodes ≠ Better Outcome
Full T24 reset (24 nodes, $6.8M, 96h) achieves the same result as surgical top-5 hardening (5 nodes, $0.8M, 6h). The 96h deployment window means the attack occurs before hardening completes.
