Security Policy

Shadow313 NEXUS takes security seriously. We welcome responsible disclosure and commit to responding within 24 hours.

Responsible Disclosure

How to Report

Send vulnerability reports to: matarmohamad313@duck.com

Subject line: [CVE DISCLOSURE] Brief description

Include: affected component, reproduction steps, impact assessment, and your contact information for credit.

Our Commitment

  • Acknowledge receipt within 24 hours
  • Provide a timeline for resolution within 72 hours
  • Credit researchers in our changelog (unless anonymity requested)
  • Not pursue legal action against good-faith researchers
  • Coordinate public disclosure timing with the reporter

Scope

✅ In Scope

  • Shadow313 CLI v1–v4 (github.com/piyyy314/Shadow313-Nexus)
  • shadow313.dev and shadow313.com web properties
  • 313-BIND temporal binding protocol implementation
  • FastAPI audit server (localhost:8000)
  • Plugin system and HMAC signing
  • Docker Compose stack and Dockerfile
  • Ollama model (matarmohamad313/shadow313-nexus)

❌ Out of Scope

  • Third-party dependencies (report upstream)
  • Social engineering attacks against team members
  • Physical security attacks
  • Denial of service attacks
  • Automated scanning without prior permission
  • Issues in third-party services (Vercel, GitHub, Cloudflare)
