⬡ Core Architecture
🌐
P2P Architecture
Fully decentralized mesh with no central server. Peers discover each other automatically via mDNS on local networks and DHT for internet-wide routing. Gossip protocol ensures resilient propagation even with high churn.
libp2p mDNS DHT Gossip No SPOF
📦
Shared Intel Types
Peers share enriched, structured threat intelligence across the mesh. Each package is typed, versioned, and schema-validated before propagation to downstream peers.
IOCs CVE Enrichments MITRE ATT&CK Honeypot Captures Malware Hashes
🔐
Trust Model
Every intel package is cosign-signed before emission. Peers maintain a reputation score for each neighbour. Low-trust or malformed packages are silently rejected; repeated offenders are automatically quarantined.
cosign Reputation Score Package Signing Auto-Quarantine
🔒
Privacy
Differential privacy noise is injected into shared data to prevent peer fingerprinting. Zero-knowledge attestation lets peers prove intel validity without revealing source identity. Sharing is always opt-in only.
Diff. Privacy ZK Attestation Opt-In Only No Fingerprinting
